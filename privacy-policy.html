KOTOBA·AI 隐私政策

最后更新：2026 年 7 月 23 日

核心要点

KOTOBA·AI 是开源免费软件（GPL-3.0），所有数据 100% 本地存储、零云端上传；除向 DeepSeek API 发送学习内容用于 AI 生成与批改外，其余功能完全离线。

1. 信息收集与使用

KOTOBA·AI 是一款本地运行的桌面软件。我们不收集、不存储、不上传您的任何个人信息。您在软件中产生的所有数据（详见第 2 条）仅保存在您设备的本地文件系统中，我们无法访问，也不会访问。

当您使用 AI 出题和批改功能时，您输入的笔记内容和答题数据会被发送至 DeepSeek 的 API 服务器进行处理。这是唯一涉及数据传输的场景。有关 DeepSeek 如何处理您的数据，请参阅 DeepSeek 隐私政策。

2. 本地存储的数据类型

以下数据存储在您设备上（位于 KOTOBA·AI 数据目录中），均不会上传至任何服务器：

  • API 密钥：您的 DeepSeek API Key，用于调用 AI 服务
  • 学习笔记：您粘贴的语法笔记和单词列表
  • 答题记录：每道题的作答内容、AI 批改反馈和得分
  • 错题本：被自动收录的错误题目及错误详情
  • 知识库：已学习语法点的追踪数据和艾宾浩斯复习进度
  • 个人设置：级别偏好、主题选择、教材选择等配置

3. 数据安全

您的数据安全完全取决于您对自己电脑的保护。您应当：

  • 妥善保管您的 DeepSeek API Key，不要分享给他人
  • 定期检查 DeepSeek 平台的 API 使用量，确保 Key 未被泄露
  • 如发现 API Key 泄露，立即在 DeepSeek 平台重置 Key

KOTOBA·AI 无法访问您的设备，因此无法为数据丢失或泄露承担责任。建议定期备份您的学习数据。

4. 第三方服务

KOTOBA·AI 仅依赖一个第三方服务：

  • DeepSeek API（深度求索）：用于 AI 题目生成和答案批改。当您使用这些功能时，笔记内容和答题数据会通过加密的 HTTPS 连接发送至 api.deepseek.com。DeepSeek 对其 API 调用数据的处理受其自身隐私政策约束。

除此之外，KOTOBA·AI 不集成任何：分析统计 SDK、广告网络、错误追踪服务、第三方登录、CDN（所有资源本地加载）、遥测或埋点系统。

5. 用户权利

您对您的数据拥有完全的控制权：

  • 随时查看：所有数据以可读的 JSON 格式存储在本地，可用任何文本编辑器打开
  • 随时删除：通过设置页「清除数据」按钮一键删除，或手动删除对应 JSON 文件
  • 随时导出：练习总结可下载为 Markdown 文件；历史记录和错题本可通过复制 JSON 文件导出
  • 无需注册：本软件不要求创建账户、不收集邮箱、不需要手机号

6. 开源协议

KOTOBA·AI 基于 GPL-3.0 许可证开源发布。您可以自由地：

  • 使用、复制、修改、分发本软件
  • 将本软件用于个人学习目的
  • 分发修改版，前提是同样采用 GPL-3.0 并提供源码

保护机制：GPL-3.0 是 copyleft（传染性）许可证——任何基于本软件的衍生或修改作品，若对外分发，必须同样以 GPL-3.0 开源并公开源码，从而防止闭源商业剽窃。完整的 GPL-3.0 许可证文本随软件一同分发（LICENSE 文件）。

7. 免责声明

本软件按「现状」提供，不提供任何明示或暗示的保证。在任何情况下，作者或版权持有人均不对因使用本软件而产生的任何索赔、损害或其他责任负责。

AI 生成的题目和批改内容仅供参考学习，不构成专业教育建议。用户应对自己的学习效果负责。

8. 未成年人保护

本软件为教育工具，内容不包含任何不适宜未成年人的信息。但我们建议未成年人在监护人指导下使用本软件及配置 API Key（涉及付费服务）。

9. 隐私政策更新

我们可能会不时更新本隐私政策。更新后的政策将随软件新版本一同发布。重大变更将在软件的更新日志中注明。
